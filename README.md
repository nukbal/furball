# Furball

hobby gui app for compressiong media files (mainly image, video) powered by [Native SDK](https://github.com/vercel-labs/native)

## Features
- image compression
- image pdf archiving
- zip archiving
- super resolution
- zip detection
- pdf detection
- pdf image conversion
